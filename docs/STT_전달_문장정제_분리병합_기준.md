# [STT 전달] 정답지 문장 정제 · 분리 · 병합 기준

우리(VA/TA) 측이 TM 스크립트 원문을 아래 순서로 가공하여 **분석용 정답지 문장**을 생성합니다.
STT 문장도 이 기준(제거 규칙 / 문장 분리 / 문장 병합)에 맞추면 유사도 매칭이 좋아집니다.

처리 순서: **원문 → (1) 텍스트 정제 → (2) 문장 분리 → (3) 문장 병합(어미 재결합) → 최종 정답지**

---

## (1) 텍스트 정제 — 제거/치환

아래를 위에서 아래 순서대로 적용합니다.

### 1-1. 괄호/태그 내부 삭제 (안의 내용까지 통째로 제거)
- HTML 태그 : `<(/)?([a-zA-Z]*)(\s[a-zA-Z]*=[^>]*)?(\s)*(/)?>`
- 꺾쇠 `< >` 안 : `\<(.*?)>`
- 대괄호 `[ ]` 안 : `\[(.*?)]`
- 소괄호 `( )` 안 : `\((.*?)\)`
- 변수 `$ $` 안 : `\$(.*?)\$`

### 1-2. 기호 치환
- 물음표 `?` → 마침표 `.` 로 변경
- `www.aig.co.kr` → `더블유더블유쩜에이아이지쩜씨오쩜케이알` (마침표 때문에 문장이 잘못 잘리는 것 방지)

### 1-3. filter1 — 특수문자 제거 (해당 문자를 공백으로 치환)
제거 대상(총 20개):
```
&nbsp;   &lt;(<)   &gt;(>)   ,   -   ^^   !   /   ■   ▶   ◈
‘   ’   “   ”   •   *   ※   :   "(직선 큰따옴표)
```
※ 직선 작은따옴표(`'`)는 제거 목록에 **없음** → 정답지에 `'` 가 남을 수 있음.

### 1-4. filter2 — 넘버링/특약번호 제거 (공백으로 치환)
제거 대상(총 10개):
```
1) 2) …(숫자1자리+])      10) 12) …(숫자2자리+])      "1. " "2. "(숫자+마침표+공백)
특약01(특약+2자리)          특약1(특약+1자리)           특약 1(특약+공백+1자리)
Yes)      No)      ① 예      ② 아니요
```

### 1-5. filter3 — 고정 안내문구/맨앞 마침표 제거 (공백으로 치환)
제거 대상(총 11개):
```
or
변경된 내용 진행     필수 :      (진행~필수 사이 공백 5칸 버전)
변경된 내용 진행  필수 :         (공백 2칸 버전)
추가된 내용 진행  필수 :
CT 검사비 언급시 필수멘트:
★ 치과  한의원  한방병원 언급시 필수멘트:
부담보조건부 인수스크립트 :
피보험자)
계약자 진행)
암진단비)
문자열 맨 앞의 마침표(.)  →  ^[\.]*
```

---

## (2) 문장 분리 기준

정제된 텍스트를 아래 정규식으로 분리합니다.
```
split 정규식 :  (?!(?<=\d)\.)(\.)|(시고)|(하며)
```

분리 규칙:
1. **마침표(`.`)** 를 만나면 분리한다.
   - 단, **숫자 바로 뒤의 마침표**(소수점·날짜: `1.5%`, `2026.04.02`)는 분리하지 않는다.
2. 연결어미 **`시고`**, **`하며`** 가 나오면 그 자리에서 분리한다.
3. 분리 후 **공백 제거 시 1글자 이하인 조각은 버린다.**

---

## (3) 문장 병합 기준 (어미 재결합)

(2)에서 잘린 조각이 **연결어미로 끝나면**, 문장이 어색하게 끊긴 것으로 보고 **다음 조각과 공백으로 이어 붙여 한 문장으로 병합**합니다.

- 병합 판정: 조각의 **마지막 한 글자**가 아래에 해당하면 다음 조각과 병합
```
세   는   로   의   데   시   비   금   망   당   면   후
```
- 병합 조건(그룹): **같은 질의코드(QST_CD) + 같은 센터코드(CNTR_CD)** 안에서 연속된 조각끼리만 병합
- 병합까지 끝난 문장이 **최종 분석용 정답지 문장**이 됩니다.

> 참고: 소스에는 `리며`(2글자)도 병합 대상으로 적혀 있으나, 판정을 **마지막 1글자**로만 하기 때문에 실제로는 `리며`는 병합되지 않습니다. 현재 유효한 병합 어미는 위 **12개(모두 1글자)** 입니다.

---

## 요약 (STT 튜닝 관점)

- 정답지는 위 과정을 거쳐 **괄호/태그/넘버링/특정 안내문구가 제거**되고, **물음표가 마침표로 바뀐** 상태입니다.
- 문장 경계는 **마침표 / `시고` / `하며`** 기준으로 나뉘되, **숫자 뒤 마침표(소수점)는 자르지 않습니다.**
- 특정 연결어미(위 12개)로 끝난 문장은 **다음 문장과 합쳐** 완결형에 가깝게 만듭니다.
- 따라서 STT 문장도 **이 경계 규칙과 호환되게 분리/병합**하고, **구두점·기호를 같은 방식으로 정규화**하면 유사도가 올라갑니다.
  (STT가 발화를 너무 잘게 쪼개면 부분만 매칭되고, 너무 길게 뭉치면 유사도가 희석됩니다.)
