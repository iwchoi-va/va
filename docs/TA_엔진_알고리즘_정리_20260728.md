# TA 엔진 알고리즘 정리

> 결론: **TF-IDF 벡터화 + 코사인 유사도** 기반의 형태소 Bag-of-Words 문장 유사도 엔진

---

## 1. 한 줄 요약

```
TA_SCORE = round( cosine_similarity( TF-IDF(정답지 SCRIPT_TA_SENT) , TF-IDF(STT 문장) ) × 100 )
토큰화 = Mecab 형태소 분석(word/POS)
```

---

## 2. 알고리즘 상세

### 2.1 벡터화 — TF-IDF
```python
self.vectorizer = TfidfVectorizer(tokenizer=self.tag.tokenizer, analyzer='word', min_df=1, max_df=1.0)
self.tfidf = self.vectorizer.fit_transform(self.doc_all)   # 콜별 정답지 문장 집합
```
- **콜 단위로** 그 콜에 해당하는 정답지 문장들만 모아 TF-IDF 행렬 생성
- `min_df=1, max_df=1.0` → 문서빈도 필터링 사실상 없음(작은 코퍼스)

### 2.2 유사도 — 코사인
```python
new_tfidf = self.vectorizer.transform([_sentence])          # STT 문장 1개
self.cos_similarities = linear_kernel(new_tfidf, self.tfidf).flatten()
```
- `linear_kernel`(내적)이나 TF-IDF가 **L2 정규화**되어 있어 결과는 **코사인 유사도**
- 정답지 전체와 비교 후 **내림차순 정렬**하여 top-N, 임계값 이상만 채택 (`ds.pyx:102,109`)

### 2.3 토큰화 — Mecab 형태소
```python
self.tagger = Mecab()                                        # konlpy Mecab
docs_tokens = ['/'.join(t) for t in self.tagger.pos(_docs)]  # 'word/POS' 토큰
```
- 문장을 **형태소(word/POS) 단위**로 토큰화하여 TF-IDF 입력으로 사용
- **기본 설정상 품사필터·불용어 OFF** (`tagger()` 기본값 `_use_tag_filter=False, _use_stopwords=False`)
  → 명사·동사 어간뿐 아니라 **조사/어미까지 전부 토큰**에 포함
- 준비돼 있으나 미사용:
  - 품사필터 후보 `tag_filter = ['NNG','NNP','VV','SL','SN']` (일반명사/고유명사/동사/외국어/숫자)
  - 복합어 사전 `com_dict.txt`, 불용어 `stopwords.txt`

### 2.4 점수·임계값
- **`TA_SCORE = round(cosine × 100)`** → **0~100** 스케일
- 엔진 기본 임계값 **`threshold = 0.6`** (=60점) 이상만 `ms_regu_score`에 저장
  → 우리 시스템 `QST_RATE` 기본값 **60**과 정합
- 임계값·결과 개수는 `set_ds_options`로 설정(`config`)

## 3. 처리 파이프라인

1. **콜 수집** (`read_contents`, `dataproc.py:69`)
   `ms_stt_rslt_merge.CONTENT` 조회 — 조건: `STT_FLAG='Y' AND TA_FLAG='N' AND BATCH_YN='N' AND ENC_FLAG='N'`, `TOP(50)`
2. **처리중 표시** → `TA_FLAG='S'`
3. **정답지 조회** (`read_script_map`, `dataproc.py:88`)
   `ms_script_sent.**SCRIPT_TA_SENT**` + `QST_RATE`, `QST_KEYWORD` 등 — 상품/담보/계피구분/질의유형(TB_QST_KIND_MNG) 조건으로 해당 콜에 유효한 정답지만 필터
   - 스크립트 없으면 → `TA_FLAG='E'`
4. **벡터화** → 콜의 정답지 문장들로 TF-IDF 학습
5. **CONTENT 파싱** (`_read_db_contents`, `proc_base.py:182`)
   - **재분할이 아니라 포맷 파싱만** 함: CONTENT를 `\n`(줄) 단위로 나누고, 각 줄을 탭으로 분리해 필드 추출
   - 줄 포맷: `RXTX_GB | start_time <TAB> end_time <TAB> 문장텍스트` → 문장(4번째), start_time(2번째), 화자(1번째)만 뽑음
   - 예)  RX|20340	32140	가입에 동의하시죠
   - **문장 경계는 STT가 CONTENT에 넣은 줄(`\n`) 그대로** 사용 → 엔진은 재분할/병합/정제(filter·연결어미) 안 함
   - 파싱한 STT 문장은 DB에 저장하지 않고 메모리에서 유사도 계산에만 사용
6. **유사도 계산** (`__run_extraction`)
   - STT 문장마다 정답지 전체와 코사인 유사도 → threshold 이상 매칭 채택
   - **STT 문장 10자 미만 스킵**, 화자(RXTX_GB) 반대측 스킵
7. **결과 적재**
   `ms_regu_score`에 `TA_SCORE`, `START_TIME`, 매핑키(SC_SNO/…/SCRIPT_SENT_ID, STT_SENT_ID) INSERT (중복 없을 때만)

## 4. 입출력 데이터 요약

| 구분 | 대상 | 컬럼 |
|------|------|------|
| 입력(STT) | `ms_stt_rslt_merge` | `CONTENT` (콜 원문) |
| 입력(정답지) | `ms_script_sent` | **`SCRIPT_TA_SENT`**, `QST_RATE`, `QST_KEYWORD`, 매핑키 |
| 입력(대상/조건) | `ms_stt_meta` 외 | `STT_FLAG/TA_FLAG`, PROD_CD, DMBO_CD, 계피구분, 질의유형 등 |
| 출력(점수) | `ms_regu_score` | `TA_SCORE`(=cos×100), `START_TIME`, 매핑키 |
|                 |                     |                                                             |

> `SCH_SCORE`(키워드 0/100)는 이 유사도 엔진이 아니라 검색(키워드) 로직에서 산정. 본 엔진은 `TA_SCORE`(유사도) 담당.

## 5. 이 알고리즘의 특성 → 점수 저조 원인과 연결

| 현상 | TF-IDF 코사인 관점 원인 |
|------|-------------------------|
| **긴 STT 문장에서 점수 급락(희석)** | 코사인은 공유되지 않는 토큰이 많을수록 하락. 긴 STT 문장에 정답지 토큰 비율이 낮으면 유사도↓ — 희석의 **수학적 직접 원인** |
| **어미/문형 차이(하시죠 vs 하세요) 감점** | 형태소로 어간은 매칭되나, **품사필터 OFF라 어미/조사 토큰이 달라 감점**. 의미 임베딩이 아닌 표층 형태소 매칭 |
| **숫자 표기(3 vs 삼) 불일치** | `SN`(숫자)/명사 토큰이 글자 그대로 비교 → `3백만원 ≠ 삼백만원`. 표기 통일 필요 |
| **동의어/유의어 미인식** | BoW 특성상 사전에 없는 동의어는 다른 토큰으로 취급 |

## 6. 개선 방향 (참고)

1. **부분 구간(슬라이딩) 코사인** — 긴 STT 문장 내에서 정답지와 가장 유사한 구간을 찾아 점수화 (희석 완화, 최우선)
2. **품사필터/불용어 ON** — 코드에 이미 `tag_filter=['NNG','NNP','VV','SL','SN']`, `stopwords.txt`가 준비돼 있으나 **기본 OFF**. 켜면 어미·조사 노이즈 제거로 어미차이 문제 완화 (단, 짧은 문장은 토큰이 줄어 역효과 가능 → 검증 필요)
3. **숫자·기호 표기 정규화** — 정답지↔STT 숫자 표기 통일(콤마 제거, 소수점 유지 등)
4. **복합어 사전(com_dict) 보강** — 보험 도메인 용어를 하나의 토큰으로 묶어 매칭 정확도 향상
5. **(중장기) 문장 임베딩 기반 의미 유사도** — SBERT 등 도입 시 어미·동의어·길이 문제를 근본적으로 개선
